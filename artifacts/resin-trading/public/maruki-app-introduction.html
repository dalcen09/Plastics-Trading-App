1. Overview

The MARUKI Resin Trading Management System is a browser-based platform designed to centralise and streamline plastic resin trading operations. It provides a single workspace for recording supply sources (仕入), sales demand entries (販売先), and automatically discovering compatible matches between them — replacing fragmented spreadsheets with a structured, searchable, and real-time system.

The application runs in any modern web browser with no installation required, and is accessible from desktop computers, tablets, and smartphones.

2. Resin Categories

All entries are organised into three categories, each with its own dedicated page in the navigation:

Category Japanese Sidebar Label Description
Virgin バージン VG First-use, unprocessed resin direct from manufacturers
Off-grade オフグレード OG Below-standard or surplus grade resin
Recycled リサイクル 再生 Post-consumer or post-industrial recycled resin

3. Application Layout & Navigation

The application is divided into a left sidebar for navigation and a main content area on the right. The sidebar is always visible on desktop and slides in as a drawer on mobile devices.

Sidebar Sections

  • VG / OG / 再生 — Direct links to the Virgin, Off-grade, and Recycled category pages.
  • マッチング分析 — Matching Analysis hub, with sub-links for each category showing per-category match counts.
  • ゴミ箱 — Recycle Bin, showing the count of soft-deleted items. Pinned to the bottom of the sidebar.

4. Supply & Demand Tables

Each category page contains two tables: 仕入 (Supply) and 需要 / 販売先 (Demand), toggled by tabs at the top of the page. Both tables work identically.

Adding a Record

Click the ＋ 仕入を追加 (or 需要を追加) button in the top-right corner. A row editor dialog will appear with fields for counterparty, resin type, manufacturer, grade, MI, quantity, price, and more. Click 保存 to save.

Editing a Record

Click the ✏️ pencil icon in the row's action column to open the same editor pre-filled with the existing values. After making changes, click 保存.

Deleting a Record

Click the 🗑️ trash icon in the row's action column. The record is moved to the Recycle Bin — it is not permanently deleted and can be restored.

Search & Filter

Use the search bar to instantly filter by counterparty, manufacturer, or grade. Click 絞り込み to open the advanced filter panel with options for resin type, sub-type, MI range, quantity, price, date range, and open/closed status.

Sorting

Click any column header to sort ascending or descending. An arrow indicator (↑↓) shows the current sort direction.

Column Visibility (列)

Click the 列 button to open the column picker. Check or uncheck any column to show or hide it. Use すべて表示 to show all, or すべて非表示 to hide all.

Open / Closed Status

Each entry has an オープン / クローズ toggle in the rightmost column. Clicking it switches the status. Closed entries are excluded from matching analysis but remain visible in the table for record-keeping.

Match Badges: If an entry has compatible matches, a green ⚡ N件マッチ badge appears below the counterparty name. Clicking the badge navigates directly to the Matching Analysis page filtered to that entry.

5. Excel Import & Export

Importing Data

Click データインポート in the top toolbar. Select an Excel file (.xlsx) from your computer. The system reads Japanese column headers and maps them to the correct fields automatically. A preview is shown before confirming. Existing records are not overwritten — imported rows are added as new entries.

Exporting Data

Click Excelエクスポート to download the current table (all records matching any active filter) as an Excel file. The exported file uses Japanese column headers and is compatible with Excel and Google Sheets.

6. Matching Analysis (マッチング分析)

The system automatically compares every active supply entry against every active demand entry within the same resin category and identifies compatible pairs. Results are displayed as match cards, each showing the supply-side and demand-side details side by side.

Compatibility Score

Each match is assigned a numeric score based on how many criteria are satisfied (category, resin type, sub-type, MI range, etc.). A higher score indicates a closer match. The criteria that contributed to the score are shown as tags on the match card.

Filtering by Category

The sidebar under マッチング分析 shows three sub-links — バージン, オフグレード, and リサイクル — each with the number of matches for that category. Clicking one filters the Matching Analysis page to show only that category's results.

Navigating Back to the Table

Each match card shows a テーブルで確認 link on both the supply and demand panels. Clicking it navigates directly to the relevant row in the source table, highlighted in green.

7. Recycle Bin (ゴミ箱)

When a record is deleted from any category table, it is soft-deleted — moved to the Recycle Bin rather than immediately removed from the database. This provides a safety net against accidental deletions.

Restoring a Record

Click 復元 next to any item to restore it back to its original table. It will reappear as an active entry immediately.

Permanent Deletion

Click 完全削除 to permanently remove a single record. A confirmation dialog appears before the deletion is carried out. This action cannot be undone.

Bulk Actions

Use the checkboxes to select multiple items, then click まとめて復元 or まとめて完全削除 from the toolbar that appears at the top. This allows processing many records at once.

8. Mobile Access

The application is fully usable on smartphones and tablets. On smaller screens the sidebar is hidden by default. Tap the ☰ hamburger icon in the top-left corner to open the navigation drawer.

Tapping any menu item navigates to that page and automatically closes the drawer. Tapping the dark overlay area to the right of the drawer also closes it.

9. Data & Deployment

All data is stored in a dedicated PostgreSQL database that is entirely separate from the application code. This means:

  • Data persists across browser sessions and application restarts.
  • When the application is updated or re-deployed, all existing records are preserved automatically.
  • The only scenario where data structure changes is when a new feature explicitly adds database columns — in which case existing records are kept and the new column receives a default value.
No installation required. The application is accessed via a URL in any modern web browser. Supported browsers: Chrome, Edge, Firefox, Safari (desktop and mobile).
